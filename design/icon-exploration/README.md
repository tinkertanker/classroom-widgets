# Icon exploration (working files)

Working material for the universal Classroom Widgets icon system — colour app
icon (macOS, Windows, Linux, PWA) plus a monochrome menu-bar/tray glyph. Kept on
this branch so the exploration survives ephemeral build containers; remove this
folder before merging the final icon.

- `scripts/design-workflow.js` — nine designers per round, one direction each.
- `scripts/eval-workflow.js` — nine evaluator lenses score every concept from
  rendered contact sheets.
- `scripts/render.mjs` — renders contact sheets (macOS light/dark, full-bleed
  derivation, favicon, menu bar, Windows taskbar, GNOME bar, pixel zoom).
- `scripts/aggregate.mjs` — tallies scores, top-3 votes, verdicts and riffs.
- `data/` — concept SVGs, briefs and evaluations per round.
- `sheets/` — rendered contact sheets.
