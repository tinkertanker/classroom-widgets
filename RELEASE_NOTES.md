A clearer widget chooser and improvements to floating widgets and Display.

- All platforms: the widget chooser groups widgets into category columns with descriptions, search and keyboard navigation. Narrow windows use a stacked layout.
- All platforms: the desktop launcher follows the system's light or dark appearance.
- All platforms: editing a widget no longer unnecessarily brings other widget windows forward or interrupts their focus.
- All platforms: group arrangement controls appear only when at least two widgets are visible. Individual position and size controls remain available.
- Timer: new timers start at one minute, and the time display keeps scaling when the widget is enlarged.
- macOS: Display capture resolution adapts after resizing the preview, avoiding unnecessarily large captured frames.
- Windows: Display capture runs off the UI thread to keep the preview controls responsive, and the source menu stays anchored to its button after resizing.
- macOS: opening About brings the panel to the front.
