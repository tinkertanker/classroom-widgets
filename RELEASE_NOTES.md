Desktop link shortening for macOS, Windows, and Linux.

- Open Link Shortener as a floating widget. TinyURL works without sign-up; choose spoo.me or your own Short.io public key and branded domain in **Settings → Link Shortener**.
- Provider settings are saved on the computer and shared by all Link Shortener and QR Code widgets, including newly opened windows. The widget's settings gear opens the app's native Settings window.
- QR Code can shorten a link before encoding it. If the provider fails or takes longer than 15 seconds, the original URL's QR code remains available.
- The website keeps its existing build-time Short.io configuration; no runtime provider picker or QR-shortening controls are added to the web app.
