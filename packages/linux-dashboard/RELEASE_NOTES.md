First Linux release. Classroom Widgets now runs as a system-tray app on Linux desktops with the same floating widgets as the macOS menu-bar and Windows tray apps.

- AppImage (self-contained, no install) and `.deb` packages.
- Widgets float above other apps (Always on Top), with adjustable background transparency; the title bar and controls fade out when the mouse leaves.
- Tray menu: Add Widget, Arrange in Row / Column, Reload, Settings, Launch at Login (XDG autostart), Open Full Web App.
- Widget positions are remembered between launches.
