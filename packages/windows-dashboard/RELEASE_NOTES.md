First Windows release. Classroom Widgets now runs as a system-tray app on Windows 10/11 with the same floating widgets as the macOS menu-bar app.

- Per-user installer (no admin rights) with a **Start Classroom Widgets automatically when I sign in** option, plus a portable zip.
- Widgets float above other apps (Always on Top), with adjustable background transparency; the title bar and controls fade out when the mouse leaves.
- Tray menu: Add Widget, Arrange in Row / Column, Reload, Settings, Launch at Login, Open Full Web App.
- Widget positions are remembered between launches.
